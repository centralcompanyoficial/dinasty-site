# Site do Dinasty

Site oficial (dinastyperformance.com.br). A Hostinger publica este repositório sozinha a cada mudança.

- O instalador fica em Releases; `download/Dinasty-Instalador.exe` redireciona pra versão mais nova (`.htaccess`).
